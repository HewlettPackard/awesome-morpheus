# Skills

Self-contained Copilot skills (folder + `SKILL.md`) for task-specific Morpheus workflows — e.g. provisioning an instance, rotating credentials, or generating a cost report through the Morpheus API.

To contribute one, see [Contributing](../CONTRIBUTING.md#agents--skills).

Each skill should live in its own folder (`skills/<skill-name>/SKILL.md`, plus any bundled assets/scripts), following the same format as [github/awesome-copilot](https://github.com/github/awesome-copilot/tree/main/skills).
