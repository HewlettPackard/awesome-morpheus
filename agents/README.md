# Agents

Custom Copilot agents (`*.agent.md`) that interact with Morpheus Data — e.g. via its REST API, CLI, or SDK — to automate provisioning, operations, or governance tasks.

To contribute one, see [Contributing](../CONTRIBUTING.md#agents--skills).

Each agent should be a single self-contained `<name>.agent.md` file with YAML frontmatter (`name`, `description`, `tools`) followed by the system prompt, following the same format as [github/awesome-copilot](https://github.com/github/awesome-copilot/tree/main/agents).
